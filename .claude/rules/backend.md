# 后端规则

- Controller只负责鉴权、参数校验和调用Service
- 业务规则放在Service或明确的领域函数中
- 数据库访问通过项目已选定的ORM
- 禁止在统一LLM客户端之外调用模型API
- 所有模型结构化输出必须经过JSON解析和Schema校验
- 评估、题纲和终判失败不得静默
- 不引入Redis、消息队列或微服务

## 配置

以下内容必须从配置文件读取：

- Prompt
- 问卷题目
- 阶段目标和轮次
- 工具任务
- 等级定义
- 题纲黑名单

不要在业务代码中复制配置内容。

## 业务规则追溯

涉及以下内容时，在代码或测试中标明对应PRD章节：

- 阶段推进
- S1.3触发
- 面试官环节触发
- L3/L4 pending规则
- 结论锁定
- A/B/C一致性计算
